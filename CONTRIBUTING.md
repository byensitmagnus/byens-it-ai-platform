# Produktfeedback og bidrag

Beskriv opgaven, det forventede resultat og det faktisk observerede resultat.
Skriv hvilken side/version og browser der blev brugt. Et lille, anonymiseret
reproduktionseksempel er bedre end private logs eller screenshots med kundedata.

Issues kan indeholde fejl eller konkrete forbedringsforslag. Ved kodebidrag
beskrives ændring og relevant browserkontrol; ingen nye dependencies uden et
konkret behov. Byens IT vurderer bidrag før integration og publicering.

Dette repo er offentligt læsbart, men har ikke en open-source-licens. Se LICENSE.
Sikkerhedsproblemer hører til den private kontaktvej i SECURITY.md.
